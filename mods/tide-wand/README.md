# Tide Wand

The tide wand has two casts.

Use it to launch yourself along the direction you are looking, with a little extra lift. Sneak and use it on a block to open a well for eight seconds. The well pulls in dropped items and gives anyone standing in it a gentle rise, capped a few blocks above the spot so it is not a flight spell. Mobs are not affected.

Both casts spend durability and respect a cooldown. Repair the wand with amethyst shards. The recipe is an ender pearl, an amethyst shard, and a breeze rod.

## Config

`config/tide-wand.json` controls launch speed and lift, both cooldowns, well duration, radius, item pull, and durability costs. Speeds and radii are clamped so a bad edit cannot turn the wand into an unbounded launcher.

## Environment

Install it on both the client and the server.
